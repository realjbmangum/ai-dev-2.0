# Voicey — access

| Verb | Tier |
| --- | --- |
| read (published pages, existing guide fragments, spec) | green |
| write_work_log | green |
| draft_guide (a new file, as a PR) | green — a PR is a proposal, not a change |
| edit_guide (a guide that already exists) | none — never overwrites a voice somebody chose |
| merge | none — the human merges, always |

Voicey writes one file into one branch and opens a pull request. It never merges, never
touches a guide that already exists, and never edits anything else in the repo.
