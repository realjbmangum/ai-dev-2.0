The outbound half is where the money and the risk both are

You already learned this the hard way on RecordStops, and the rules are written into its database: "Emailing scraped addresses in bulk from a cold domain is how a domain gets blacklisted, and the site is the asset being monetised." There, 192 businesses had an address on file and only 60 were confirmed, and that gap was the whole risk.

Patriot is in the same position, smaller. 18 of 67 have an address, and none are confirmed. So the first outbound campaign is not the sales pitch. It is the "is this still right?" mail, which earns you confirmed addresses. The pitch comes after, to people who answered.

Every safety rule carries over: send only from mail.patriot.directory so the main domain's reputation is never at stake, one mail per business per month enforced by the database rather than by an agent's judgement, and a suppression list that nothing can override.

Four

Ten directories, one of everything

You asked whether ten directories should stay separate. No, and the machine was already built for this. One engine, many properties. Adding a directory is a database and one line, not a rebuild.

Written oncePer directory
The agents: Scouty, Tidy, Mailroom, the outbound sellerIts hire terms: schedule, batch size, what to work on first
The inbox pipeline and the send rulesIts own mail domain and its own address list
This desk, these three pagesOne row in the directory picker

So Tidy is not built ten times. It is hired ten times on different terms, and a fix to how Tidy reads a website reaches all ten at their next run. The directory picker at the top of the Inbox and Fleet pages is how ten stays readable.

One thing to settle before the second directory

Right now two separate registries disagree about which routine Tidy actually is. One says one id, the other says another, and nothing checks. With one directory that is a curiosity. With ten it is how you end up unable to say what is running.

The order I would go in

  1. Fleet page with the 17 candidates. Turns a readout into a control on day one.
  2. Email routing on, and the Mailroom agent. Inbound is pure upside: businesses correcting their own listings for free.
  3. The "is this still right?" campaign. Earns confirmed addresses, which is what makes the pitch safe.
  4. The featured listing pitch, to the people who answered.
  5. Switches, log with undo, connectors.
Why that order

Selling featured listings is the revenue, so it is tempting to go first. But you have eighteen addresses and none of them confirmed, and mailing unconfirmed scraped addresses from a new domain is how the domain gets blocked. Tidy is currently earning you more addresses every Tuesday, and the confirm campaign turns those into people who have replied. The pitch is worth more to fifty confirmed businesses next month than to eighteen unconfirmed ones this week.
