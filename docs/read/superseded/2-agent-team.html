The Agent Team

Thirteen roles across four entities plus estate staff, sized to a 5-to-10-minute morning.

5 September 2026 · scope: JB Mangum, the directories, Crown and Compass, Ascend Systems, and the work log

This is not thirteen new things. Nine of them already exist in some form, scattered across five repos that cannot see each other. The work is re-homing them onto one spine, giving each a voice guide to draft against, and making every one of them report.

The budget decides the shape, not the other way round

Five to ten minutes is roughly 10 to 15 decisions. That allows exactly one drafting role to run daily. Everything else is weekly and lands on its own day. A second daily queue breaches the budget, and a breached budget is how Clippy sat at 0 approved out of 25 for a month.

Checkyneeds a tablemonthly

Full sweep testing reality against the database. Is the shop still there, is the site still up, does the page still say what the row says. Batch-first, so a dying run resumes from least-recently-checked rather than restarting at the top.

The order I would build in

1. Voicey, and run it across every surface that has no guide. It is the gate on three roles and it costs you one review session.
2. Tidy, re-homed onto the spine. One real role, reporting, end to end, before any second one.
3. The event spine, then Posty. That is the daily habit and the reason the whole thing exists.
4. Loggy, so the work log stops depending on anyone remembering.
5. Everything else, in whatever order you care about.
