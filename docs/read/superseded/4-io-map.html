One

The daily clock
Sensors land first, the Action moves them into D1, Posty drafts, you empty the desk. Loggy closes the day.
The one timing dependency worth knowing about

Posty runs 15 minutes after the last grok bot commits. If grok is late, Posty drafts without that morning's signals. It does not pretend: it checks how fresh the signals are and says so in its run report, the same way Sparky already flags a stale rulebook. A thin honest morning beats an invented one.

Notice what is not in the Reads column

No agent reads git. Not one. Guides, rules and rosters reach them through estate-api as a served copy, because 64 of your 67 repos are private and a cloud routine cannot clone them. Git is where you edit those files; D1 is where agents read what shipped.

Salesy's read is also deliberately narrow: no email, no phone, no address, no deal value. It drafts the words; you attach them to a person.

How the sensors get watched without knowing it

The ingest Action posts a run report to estate-api every time it processes a commit. So a grok bot that stops committing produces no ingest, which produces no report, which makes Watchy flag it overdue. The sensors just commit files, exactly as they do now.

This closes the hole that killed X Crew: its last report was dated 1 September, it silently missed the 2nd, 3rd and 4th, and the only reason anyone found out was a person reading a folder.

Nothing on this page publishes itself

Every row above ends at a human. That is the current design and it is worth being explicit about: this fleet is a very good writing and research assistant, not autonomous publishing. The path to changing that is the verb tier, one verb at a time, after months of drafts needing no edits. Not a switch you flip.
